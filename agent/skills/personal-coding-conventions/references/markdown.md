# Markdown

Write for the plain-text editor first.

Prefer a plain hyphen (`-`) over an em dash in prose.

Prefer short labeled lists over tables so readers can scan without a preview.

Keep source lines short. 
Break prose at sentence or phrase boundaries rather than relying on the editor to wrap long lines.
Prefer to break at punctuation rather than in the middle of a phrase.
Try to instead reduce sentence length to reduce the chance that a phrase needs to be broken in the middle.
