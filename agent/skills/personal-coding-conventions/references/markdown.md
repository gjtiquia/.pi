# Markdown

Write for the plain-text editor first.

- **Punctuation:** Prefer a plain hyphen (`-`) over an em dash in prose.
- **Lists:** Prefer short labeled lists over tables so readers can scan without a preview.
- **Source lines:** Keep lines short and never exceed 132 characters.
  Break prose at sentence or phrase boundaries rather than relying on the editor to wrap it.
  Prefer breaks at punctuation. Shorten sentences before splitting a phrase.
